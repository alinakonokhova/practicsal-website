What Are HTML and CSS?

HTML and CSS are two of the most important technologies used to build websites. Learn what they do, how they work together, and how you can use them to create your own pages.

Beginner friendly • About 9 minutes to read

1. Introduction: The Building Blocks of Websites

Have you ever wondered how a website is created? Every heading, paragraph, image, button and colorful background needs instructions that tell the browser how to display it.

Two technologies provide the foundation of most websites: HTML and CSS.

HTML defines the content and structure of a web page. CSS controls how that content looks.

A simple way to remember: HTML builds the structure. CSS designs the appearance.

You can write both HTML and CSS using a simple text editor and open your work in a web browser. You do not need expensive software to get started.

2. What Is HTML?

HTML stands for HyperText Markup Language. It is the standard markup language used to structure content on web pages.

HTML tells the browser what different parts of a page represent. For example:

  • Headings and subheadings.
  • Paragraphs and other text.
  • Images and videos.
  • Links to other pages.
  • Lists and tables.
  • Forms and input fields.

HTML uses elements, usually written with opening and closing tags.

For example, a paragraph is written like this: 

<p>Welcome to my website!</p>

The <p> tag marks the beginning of a paragraph, while </p> marks its end. The text between them is the paragraph content.

3. A Simple HTML Example

Here is a small HTML page. It contains a heading, a paragraph and a link. 

<!DOCTYPE html>
<html lang="en">
<head>
    <title>My First Page</title>
</head>
<body>

    <h1>Welcome!</h1>

    <p>This is my first website.</p>

    <a href="https://example.com">
        Visit Example
    </a>

</body>
</html>

Let's understand the main parts:

  • <!DOCTYPE html> tells the browser to use modern HTML standards.
  • <html> contains the entire HTML document.
  • <head> contains information about the page.
  • <title> sets the page title shown in the browser tab.
  • <body> contains the page content displayed in the browser.
  • <h1> creates a main heading.
  • <p> creates a paragraph.
  • <a> creates a link.
Remember: HTML is not a programming language. It is a markup language that describes the structure and meaning of web content.

4. What Is CSS?

CSS stands for Cascading Style Sheets. It is the language used to control the appearance and layout of web pages.

Without CSS, a browser can still display HTML content, but the page will usually look much simpler.

CSS allows you to control things such as:

  • Text colors and background colors.
  • Font families, sizes and weights.
  • Spacing between elements.
  • Page layouts and columns.
  • Borders, shadows and rounded corners.
  • How a website looks on phones and tablets.

CSS works by selecting HTML elements and applying style rules to them.

5. A Simple CSS Example

Imagine that your HTML page has this heading: 

<h1>Welcome to My Website</h1>

You can use CSS to change its appearance: 

h1 {
    color: #ff6b00;
    font-size: 36px;
    text-align: center;
}

Here is what each instruction means:

  • h1 selects all elements using the h1 heading tag.
  • color changes the text color.
  • font-size changes the size of the text.
  • text-align controls the horizontal alignment of the text.

The values inside the curly brackets are called declarations. Each declaration contains a property and a value.

Tip: CSS rules are written using a selector followed by curly brackets containing one or more declarations.

6. How Do HTML and CSS Work Together?

HTML and CSS are designed to work together. HTML provides the content, while CSS gives it its visual design.

For example, HTML creates this content:

<h1>Learn Web Design</h1>
<p>Start building your first website.</p>

CSS can then style the heading and paragraph: 

h1 {
    color: #070e20;
    font-size: 32px;
}

p {
    color: #4a5267;
    font-size: 18px;
    line-height: 1.7;
}

The browser combines the HTML structure with the CSS styling to display the finished page.

HTML

Provides the structure and content: headings, paragraphs, images and links.

CSS

Provides the design: colors, typography, spacing and layout.

7. What About JavaScript?

HTML and CSS are not the only technologies used to create websites.

JavaScript is a programming language that adds interactive behavior to web pages.

For example, JavaScript can:

  • Open and close navigation menus.
  • Show messages when a visitor clicks a button.
  • Check information entered into a form.
  • Update parts of a page without reloading it.
  • Create interactive tools and applications.

Think of the three technologies this way:

HTML — Structure

What appears on the page.

CSS — Design

How the page looks.

JavaScript — Behavior

How the page responds to visitors.

You can build many useful static websites with HTML and CSS alone. JavaScript becomes useful when you want to add more interactive features.

8. Create Your First HTML and CSS Page

The best way to understand HTML and CSS is to try writing some code yourself.

You only need a text editor, such as Notepad, and a web browser.

Step 1: Create an HTML file

Open Notepad and enter this code: 

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>My First Website</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>

    <h1>Welcome to My Website!</h1>

    <p>I am learning HTML and CSS.</p>

    <a href="https://example.com">
        Visit Example
    </a>

</body>
</html>

Save the file as index.html. Make sure you select All Files as the file type.

Step 2: Create a CSS file

Open another Notepad window and enter: 

body {
    font-family: Arial, sans-serif;
    background-color: #f5f7fb;
    color: #070e20;
    padding: 40px;
}

h1 {
    color: #ff6b00;
}

p {
    font-size: 18px;
    line-height: 1.6;
}

a {
    color: #ff6b00;
}

Save this file as style.css in the same folder as index.html.

Step 3: Open your website

Find index.html in your folder and double-click it. Your browser should open the page and display your heading, paragraph and link with your CSS styling.

Important: The HTML file connects to the CSS file using <link rel="stylesheet" href="style.css">. Both files must be in the same folder for this example to work as written.

9. Common Beginner Mistakes

When learning HTML and CSS, small mistakes are normal. Here are a few things to watch for:

Forgetting to close HTML tags

Many HTML elements need both an opening and a closing tag. For example: 

<p>This is correct.</p>

Using the wrong file extension

An HTML file should end with .html, and a CSS file should end with .css. Check that Notepad has not saved your file as index.html.txt.

Connecting the wrong CSS filename

If your stylesheet is named style.css, the HTML link must use exactly that filename.

Forgetting to save changes

After editing your files, save them and refresh your browser to see the latest version.

10. Key Takeaways

HTML and CSS are essential tools for building and designing websites.

  • HTML stands for HyperText Markup Language.
  • HTML defines the structure and content of a page.
  • CSS stands for Cascading Style Sheets.
  • CSS controls the appearance and layout of a page.
  • HTML and CSS work together in the browser.
  • JavaScript adds interactive behavior.
  • You can start learning with free tools.

You now understand the basic technologies behind many websites. The next step is to practice by creating and styling your own pages.
